# Jamaican Menus

Healthy, heart-friendly Jamaican menu planner (installable web app). Daily and weekly menus, 61 pork-free recipes, shopping list, favorites, "My foods" and "Never eat" lists, a Biblically clean filter, Sabbath prep-ahead option and optional private-Gist sync.

Facts are linked to the American Heart Association, FDA and USDA FoodData Central. Informational only, not medical advice. Data stays in the browser's localStorage unless the owner turns on Sync with his own token.
